# Legacy standalone pipeline (not part of the package)

Scripts from before this project became a connector: analytics, transport accessibility, municipal
socio-economic disaggregation and QA. They are **not installed, not tested and not maintained**, and they
assume an earlier 2011/2022 workbook layout that the current Stats SA ward product does not have.
Kept for reference only; port anything you need onto `get_south_africa()`.
